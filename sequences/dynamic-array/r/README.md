# Growth of a Dynamic Array (R)

`growth_by_2.r` draws the capacity of an array that doubles when it is
full, as shown in the [Dynamic Arrays](https://franckc.folk.ntnu.no/idata2302/2026/sequences/dynamic_arrays.html)
lecture notes. It needs the `areaplot` package.

```shell
$ Rscript growth_by_2.r
```
