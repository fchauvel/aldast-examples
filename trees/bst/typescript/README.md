# Binary Search Trees (TypeScript)

Two implementations of an ordered set as a binary search tree, from the
[Binary Search Trees](https://franckc.folk.ntnu.no/idata2302/2026/trees/bst/index.html) lecture notes:

- `bst.ts`: recursive operations
- `iterative.ts`: iterative operations

Both files include their tests. They run with [Deno](https://deno.com):

```shell
$ deno test bst.ts
$ deno test iterative.ts
```
