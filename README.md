# Code Examples for IDATA 2302

Code examples that accompany the lecture notes of NTNU's *IDATA 2302,
Algorithms and Data Structures*. The notes are available on the
[course website](https://github.com/fchauvel/ntnu-idata2302-website).

The examples are organised by module, then by topic, and finally by
programming language:

    <module>/<topic>/<language>/

Each topic folder has a short README and, when available, its tests.

## Examples

| Module | Topic | Languages |
|---|---|---|
| Sequences | [Jump search](sequences/jump-search/java) | Java |
| Sequences | [Fixed and dynamic arrays](sequences/dynamic-array/c) | C |

Other modules are moved here one at a time.
